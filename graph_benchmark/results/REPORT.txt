========================================================================
  1. ARCHITECTURE
========================================================================
Sweep Neural Mesh Architecture:
  - GraphReasoningEngine: deterministic graph algorithms (BFS, Dijkstra, DFS)
  - Integration Hub: consensus engine for evidence aggregation
  - ReasoningCortex: 8 processing centers + explanation narrator
  - Synaptic plasticity: LTP/LTD, STDP, myelination
  - 3-Division brain: hindbrain (evidence scoring), midbrain (world knowledge),
    forebrain (logical inference, common sense, planning)

OpenAI Reference:
  - Model: o1
  - Published Graphwalks BFS <128K: 62.0%
  - Source: OpenAI published Graphwalks benchmark

Key architectural difference:
  Sweep uses deterministic graph algorithms for traversal tasks.
  OpenAI o1 uses learned neural reasoning over token sequences.
  This means Sweep achieves perfect accuracy on well-defined graph tasks,
  while LLM accuracy degrades with graph size and complexity.
